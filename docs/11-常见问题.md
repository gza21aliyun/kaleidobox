# 常见问题

## 搜刮相关

### 为什么 DMM / Getchu 搜出来的数据不对？

部分 DMM 和 Getchu 游戏有专属排版，可能拿不到正确的数据。遇到问题请提 Issue。

### Getchu 的游戏看不到图？

Getchu 源如果不选择自动下载图片，会看不到图。

### 搜刮时同时选多个源好吗？

同时搜几个源会使数据混乱，不推荐。分批次按源搜刮问题不大。推荐先用批评空间联合搜刮拿到 dlsite/dmm/getchu 的 ID，再按需分源补搜。

### Hikarinagi 提示未授权？

Hikarinagi 是公共客户端 OAuth 授权，需要在设置中完成一次应用内授权。批量任务在未授权时会静默跳过，只有手动操作才弹"去授权"提示。

### 搜刮结果显示中文，但我想要原文？

检查设置中的 **「优先获取中文信息」（SearchCn）** 开关——关闭后搜刮结果显示原文标题与简介。

## 评论相关

### 评论加载失败？

- 评论是**实时加载**的，不存本地
- Bangumi 评论失败的话，先到设置里更新 Token
- 确认该游戏已匹配到对应源的 ID（没匹配 ID 的源无法看评论）

## 备份相关

### 多台设备的存档怎么同步？

开启云备份后在设置中打开 **「启动前自动同步云端存档」**，启动游戏前会自动恢复较新的云端存档。详见 [存档与云备份](07-存档与云备份.md#存档云同步140-新增)。

### 恢复云端备份会不会丢当前存档？

不会。恢复前当前本地存档会先自动备份到 `pre_restore/` 目录。

### 旧版本上传的云备份还能用吗？

能。旧格式备份（文件名只有备份时刻）自动兼容，新旧比较时回退使用备份时刻。

## 手柄相关

### 手柄连不上？

- DualSense：需要 USB 连接
- DS4：可蓝牙连接
- NS Pro：可蓝牙连接，但需要安装 BetterJoy 驱动
- XInput 设备：直连

### 键位映射没生效？

启动映射需要设置好**进程名**。选自动的话需要等待检测完成，可在游玩配置里设置检测时间。

## 其他

### 游戏库/分类页画廊里的图片没更新？

截图后画廊会自动刷新；如果图片尚未滚动进可视区域，滚动出现后会补拉取。

### 视频播放不了？

`ffmpeg.exe` 放在程序目录下或自行设置路径；显卡驱动要跟 ffmpeg 版本兼容。
