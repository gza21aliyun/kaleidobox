# 快速开始

## 系统要求

- Windows 10/11（64 位）

## 安装

前往 [Releases](https://github.com/gza21aliyun/kaleidobox/releases) 页面下载最新版本的安装包，安装后启动即可。

也可以从源码构建，参见项目 [README](../README.md#从源码构建)。

## 首次启动

启动后进入主页，可以看到游玩统计、最近游戏等信息：

![主页](../screenshot/home.png)

首次使用建议按以下顺序配置：

1. **添加游戏** —— 见 [游戏库与导入](02-游戏库与导入.md)
2. **搜刮元数据** —— 见 [元数据搜刮](03-元数据搜刮.md)
3. **设置存档位置**（如需备份/下载存档）—— 见 [存档与云备份](07-存档与云备份.md)

## 界面总览

| 页面 | 说明 |
|------|------|
| 主页 | 游玩统计、最近游玩的游戏 |
| 游戏库 | 全部游戏，支持列表/小图/大图/画廊四种显示模式 |
| 分类页 | 按品牌、系列、类型、人设、剧本等维度归类浏览 |
| 标签页 | 管理标签分类与分组 |
| 游戏资源页 | Getchu 每月游戏、BT 搜索下载 |
| 已下载文件页 | 管理下载文件夹，批量解压/安装/导入 |
| 任务页 | 后台任务状态与结果 |
| 设置 | 全部配置项 |
