# 评论与攻略

## 评论

支持查看以下来源的评论和评分：

- **批评空间** —— 支持查看详细评论
- **DLSITE**
- **DMM**
- **Bangumi** —— 加载失败的话先到设置里更新 Token
- **Hikarinagi** —— 需完成应用内 OAuth 授权（未授权时会弹窗引导）

![评论](../screenshot/review.png)

> **注意**：评论是**实时加载**的，不会存入本地数据库。要看评论，需要在搜刮时先匹配到对应源的 ID（见 [元数据搜刮](03-元数据搜刮.md#来源-id-管理)）。

## 攻略板块

内置攻略板块，能查看来自诚也（存档网站）的攻略文档。
