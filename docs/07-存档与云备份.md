# 存档与云备份

## 本地备份

- 游戏存档备份保存在备份目录下的 `backups/{游戏ID}/` 中
- 可设置**游戏退出时自动备份存档**（需先设置存档位置）
- 本地备份保留数量可在设置中调整

### 存档位置

- 在游戏详情中设置存档路径
- 支持搜索存档位置（仍在完善中）

## 从诚也下载存档

支持从诚也（存档网站）下载存档，需先设定存档位置。

## 云备份

KaleidoBox 支持把备份上传到云端，实现多设备数据同步。支持三种存储：

### S3 兼容存储

| 配置项 | 说明 |
|--------|------|
| Endpoint | S3 服务端点地址 |
| Region | 区域 |
| Bucket | 存储桶名称 |
| Access Key | 访问密钥 |
| Secret Key | 秘密密钥 |

（七牛、阿里云 OSS 等 S3 兼容服务均可使用）

### OneDrive

在设置页面登录 Microsoft 账号并授权即可。

### WebDAV

填入 WebDAV 服务器地址、用户名和密码。

### 云端保留策略

云端备份保留数量可在设置中调整，超出后自动清理最旧的备份。

## 存档云同步（1.4.0 新增）

多台设备游玩同一游戏时，存档可自动对齐：

1. 在设置 → 备份中开启 **「启动前自动同步云端存档」**（需先启用云备份）
2. 每次启动游戏前，应用会比较云端与本地存档的**内容修改时间**：
   - **云端较新** → 自动把云端存档恢复到本地
   - **本地较新** → 照常启动（游戏退出备份后会自动上传）

### 安全机制

- **比较的是存档内容时间**而非上传时间，不受各设备时钟差异影响
- 恢复前，当前本地存档会先备份到 `pre_restore/` 目录，怎么选都不丢数据
- 本机刚上传的云端备份不会被"恢复"回来（防回环标记）
- 刚玩完还没备份时，最近游玩时间会阻止旧云端存档覆盖
- 同步过程静默进行，仅在日志中记录；失败不阻塞游戏启动

### 存量备份兼容

旧格式的云端备份（文件名只有备份时刻）依然可用，新旧比较时自动回退。

## 数据库备份

- 支持**数据库备份/恢复**，也可导出全量备份 zip
- 可设置退出时自动备份数据库、自动上传数据库备份到云端
- 全量恢复在应用启动时自动执行待处理的恢复任务

## 手动恢复云端备份

在云端备份列表中可选择任意一份备份手动恢复；恢复前同样会做 pre_restore 本地兜底备份。
