# 画廊与截图

## 画廊

画廊可以查看官方截图和自己截的游戏图片，出现在三个地方：

1. 游戏详情页的画廊面板
2. 游戏库页的画廊模式
3. 分类页的画廊模式

![画廊](../screenshot/lib-img.png)

## 官方图片下载

- 搜刮时可选择**是否下载图片**
- **注意**：Getchu 源如果不选择自动下载，会看不到图
- 自动下载的图片按游戏分在不同文件夹，能直接打开
- 如果不同游戏用了同一个源或图片 URL 相同，可能出现图片串用问题，封面没有这个问题

## 游戏内截图

- 通过设定的**截图键**抓取游戏画面，支持手柄截图键
- 截图保存在对应游戏的画廊中
- 截图后，游戏详情页画廊、游戏库/分类页画廊模式的对应卡片都会自动刷新

## 图片查看器

- 点击图片打开图片窗口
- 支持切换图片
- 支持 Magpie 全屏查看
